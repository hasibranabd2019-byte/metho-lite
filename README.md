# METHO Lite

A separate, lightweight, mobile-first storefront for the METHO brand.

## Project principles
- Keep this project independent from the existing METHO production website.
- Use free-tier infrastructure only; do not enable paid services without explicit approval.
- Build for fast mobile browsing and reliable order submission.
- Require admin approval before any future courier handoff to Steadfast.

## Planned stack
- Cloudflare Pages for the static storefront
- Cloudflare Workers for the API
- Cloudflare D1 for application data

## Current status
Repository initialized. Application implementation, security review, deployment, Facebook in-app browser checks, and load testing are still pending.
